
# NetworkWalks – Week 4 Penetration Testing Assignment

## 1. Project Overview

This repository is created for the NetworkWalks Week 4 Penetration Testing Assignment. It is intended to organize project documentation, maintain reviewed screenshots, and demonstrate the assignment preparation and submission workflow using Kali Linux and GitHub.

The project follows responsible security-testing practices, including documentation, evidence verification, confidentiality, and responsible disclosure.

## 2. Project Objectives

- Organize the Week 4 assignment files and documentation.
- Maintain a structured project directory.
- Document the security-testing preparation process.
- Record verified progress and submission activities.
- Practice Git and GitHub version control.
- Follow ethical hacking and responsible disclosure principles.

## 6. Documentation and Evidence Management

Project documentation and screenshots should be organized and reviewed before submission.

Only verified, non-sensitive, and approved materials should be published.

Raw reconnaissance records, private evidence, database backups, private documents, and confidential security findings must remain outside this public repository unless their publication is explicitly authorized.

## 7. Responsible Disclosure and Security Guidelines

This project follows responsible security practices:

- Perform security testing only within an explicitly authorized scope.
- Do not access, copy, or disclose confidential information.
- Protect credentials, private documents, and sensitive evidence.
- Do not publish unverified vulnerabilities or security claims.
- Report potential security issues through the appropriate authorized contact.
- Preserve evidence securely and follow the instructor's submission instructions.
